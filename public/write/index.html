GitHub 연결

발행 버튼이 글과 사진을 사이트 저장소(taeholaw/leetaeho.com)에 바로 올리려면, 처음 한 번 "접근 토큰"을 넣어야 합니다. 토큰은 이 브라우저에만 저장됩니다.

  1. GitHub 토큰 만들기 화면을 엽니다.
  2. Token name: 글쓰기 / Expiration: No expiration 또는 1년
  3. Repository access: Only select repositories → leetaeho.com
  4. Permissions → Repository permissions → Contents를 Read and write로
  5. Generate token을 누르고 나온 값(github_pat_…)을 아래에 붙여 넣습니다.
